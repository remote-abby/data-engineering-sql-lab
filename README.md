# Data Engineering SQL Lab

A hands-on SQL laboratory focused on data engineering,
analytical SQL, and interview preparation.

This repository contains realistic SQL problems built around
an e-commerce data model, progressing from fundamental
queries to advanced data engineering scenarios.

## What this covers

- SQL fundamentals
- Joins
- Aggregations
- CTEs and subqueries
- Window functions
- Date and time analysis
- String manipulation
- Deduplication
- Advanced analytics
- Incremental processing
- CDC
- SCD Type 2
- Data quality
- Data reconciliation

real-world data engineering problems into reliable,
efficient SQL.
